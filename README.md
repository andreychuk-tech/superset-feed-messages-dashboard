# Связь ленты и сообщений: дашборд в Apache Superset

[![Open in GitHub Codespaces](https://github.com/codespaces/badge.svg)](https://codespaces.new/andreychuk-tech/superset-feed-messages-dashboard)

Аналитический дашборд по данным учебного симулятора приложения с лентой новостей и мессенджером. Он отвечает на вопросы: сколько пользователей пользуется лентой, сообщениями или обоими сервисами, из каких они городов, какого пола и возраста, и кто из них переписывается чаще.

![Общий вид дашборда](screenshots/1.png, screenshots/2.png,)

## Что внутри дашборда

7 графиков и блок с выводами, фильтры по периоду, городу, полу и возрастной группе.

| График | Что показывает |
|---|---|
| DAU dynamics, feed_only / msg_only | динамика пользователей, которые пользуются только лентой или только сообщениями |
| DAU dynamics, both | динамика пользователей, которые используют оба сервиса |
| Top 5 cities by DAU | пять городов с наибольшим средним DAU |
| DAU by age group | средний DAU по возрастным группам |
| DAU by gender × age | то же в разрезе пола |
| Messages by user per day | сообщений на одного отправителя в день, по полу и возрасту |
| Share of active users who send messages, % | доля активных пользователей, которые пишут сообщения |

![Срез: Москва, 18-24](screenshots/3.png, screenshots/4.png)

## Основные выводы (сентябрь 2026)

- Аудитория в основном приходит в ленту: около 20 тыс. DAU в день только в ленте против примерно 2 тыс. только в сообщениях, и всего около 300 человек пользуются обоими сервисами за день.
- Самая большая возрастная группа 18-24 (около 8 тыс. DAU в день), затем 25-34. Во всех возрастных группах мужчин больше, чем женщин.
- Москва заметно опережает остальные города (около 2.8 тыс. против 0.9 тыс. у Санкт-Петербурга).
- Сообщения пишут около 11% активных пользователей, и эта доля, как и число сообщений на отправителя (около 5.7 в день), почти одинакова для обоих полов и всех возрастных групп.
- Пол и возраст определяют размер аудитории, но не то, как часто люди переписываются.

## Что улучшено по сравнению с первой версией

- таблицы заменены графиками (таблицы читаются дольше);
- добавлены фильтры, в том числе по периоду;

- добавлен портрет пользователя: пол, возраст, интенсивность переписки и охват.

## Данные

Источник: ClickHouse учебного симулятора, таблицы `feed_actions` и `message_actions` (действия пользователей в ленте и в мессенджере). Скрипт [`scripts/feed_messages.py`](scripts/feed_messages.py) выгружает **агрегаты** без идентификаторов пользователей:

- `data/dau_segments.csv`: DAU по дням, сегменту (`feed_only`, `msg_only`, `both`), возрастной группе, полу и городу;
- `data/msg_activity.csv`: сообщения и отправители по дням, возрасту, полу и городу.

Сегмент пользователя определяется по дням: если в этот день он действовал и в ленте, и в сообщениях, это `both`. Метрики-отношения (среднее DAU, сообщений на отправителя, доля пишущих) считаются как отношение сумм, а не среднее готовых средних, поэтому корректны при любых фильтрах.


Скрипт запускается внутри JupyterHub учебной платформы: хост ClickHouse внутренний и снаружи недоступен. Параметры подключения (`CH_HOST`, `CH_USER`, `CH_PASSWORD`) задаются переменными окружения. Готовые CSV уже лежат в репозитории, поэтому для запуска дашборда доступ к ClickHouse не нужен.

## Запуск

Нужен Docker (или GitHub Codespaces, где Docker уже есть).

1. Склонируйте репозиторий и откройте его в Codespaces (кнопка выше) или локально.
2. Запустите Superset и загрузите данные одной командой:
```bash
   bash deploy/init.sh
```
3. Откройте Superset и войдите: `admin` / `admin`.
   - Локально: http://127.0.0.1:8088/
   - В Codespaces: адрес порта 8088 на вкладке **Ports** (не `127.0.0.1` и не `localhost`).
4. Dashboards → иконка импорта → выберите `dashboard/dashboard_feed_messages.zip`. Если появится запрос на перезапись, подтвердите. Подключение и датасеты вручную создавать не нужно, они приходят вместе с архивом.
5. Откройте дашборд Feed-Messages. По умолчанию выбран сентябрь 2026.

Остановить: `docker compose -f deploy/docker-compose.simple.yml down` (флаг `-v` удалит и загруженные данные).

## Замечания

- Логин `admin` / `admin`, ключ в `superset_config.py` и отключённые CSRF и Talisman подходят только для локальной демонстрации. Для публичного сервера их нужно заменить.
- Данные хранятся в SQLite (`/app/superset_home/portfolio.db`) внутри тома Docker. Это упрощение для демонстрации, не продакшен-схема.
- Данные синтетические, это результаты учебного симулятора, а не реальных пользователей.
